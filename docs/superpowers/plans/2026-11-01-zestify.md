# Zestify Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Zestify: one minimal Quickshell shell that owns the Hyprland pill, wallpaper backgrounds, palette, system surfaces, lock/session behavior, and installer.

**Architecture:** A single Quickshell process renders one bottom wallpaper window and one top pill window per monitor. Ricelin's pill/morph interaction is the UI base; Caelestia's CLI remains the palette and app-template backend; wallpapers are rendered natively with QtMultimedia using monitor-sized proxy videos. Per-monitor shell palettes come from Caelestia's scheme files; system applications always use the primary monitor's palette.

**Tech Stack:** Quickshell 0.3.1, QML/Qt 6.12, Hyprland 0.56.2, Python 3.14, Caelestia CLI 2.5.0, ffmpeg, hyprlock, UPower, PipeWire, NetworkManager, BlueZ.

**Spec:** `docs/superpowers/specs/2026-11-01-zestify-design.md`

## Global Constraints

- Project name is **Zestify**. Repo root is `~/zestify`; shell config directory is `~/.config/quickshell/zestify`; user config is `~/.config/zestify/config.json`; state is `~/.local/state/zestify/`; cache is `~/.cache/zestify/`.
- License is **GPL-3.0-only**. `NOTICE` must credit Caelestia (GPL-3.0) and Ricelin (MIT). Copied/adapted files keep a short attribution header.
- Quickshell config name is `zestify`; all runtime launch commands use `qs -c zestify`; IPC target is `zestify`.
- One Quickshell process only. Do not import Caelestia QML modules. Caelestia's Python CLI is the palette/app-template backend.
- Do not use awww, mpvpaper, hypridle, or a second shell process for session management.
- Monitors: primary `eDP-1` 1920x1200 at 0,0; secondary `HDMI-A-1` 768x1366 at -768,0, portrait. Portrait scale must use the short edge: `scale = (width < height ? width : height) / 1080`, clamped to 0.70–1.25, multiplied by `bar.scale`.
- Default bar height 34 px, top gap 8 px, dark theme. Fonts: SF Pro for UI, SF Mono for numbers, CaskaydiaCove Nerd Font for icons.
- System applications follow the **primary** monitor palette. Moving focus between monitors must never re-template applications.
- Per-monitor shell palettes come from `~/.local/state/caelestia/wallpaper/monitors/<connector>-scheme.json`; fall back to the global `~/.local/state/caelestia/scheme.json`. Missing/corrupt files fall back to the built-in dark palette, never crash.
- Effective monitor wallpaper = per-monitor override if present, otherwise global. Primary apply: save secondary overrides, run global `caelestia wallpaper -f`, restore secondary overrides. Secondary apply: `caelestia wallpaper -f -m NAME`.
- Video playback uses a lazily generated monitor-sized H.264 proxy (`~/.cache/zestify/wallpapers/<hash>/<WxH>.mp4`). The original is authoritative for palette extraction and thumbnails. If proxy generation fails, play the original; if playback fails, show the still frame.
- Video pause rules: locked, DPMS off, fullscreen window covering that monitor by default, battery below 20% on battery, power-saver profile, and optional unfocused timeout. Keep the last frame; stop decoding within 1 second.
- Session defaults: lock at 180s, DPMS off at 300s (restore on activity), suspend-then-hibernate at 600s, lock before sleep, inhibit idle while audio plays, no charging inhibit, battery warnings at 20/10/5%, critical at 3% -> hibernate after a 5s toast. `zestify sleep` locks first, then suspends.
- One expanded surface globally. Tray only on the primary monitor. Active-window title only on the focused monitor. Power menu opens on the monitor that invoked it.
- Performance budget: idle shell ≤1.5% CPU and ≤250 MB RSS; one monitor-sized video proxy ≤5% CPU, two ≤9%; no 4K decoding in steady state when proxying succeeds; 60fps transitions only; stats poll 1s, battery 30s; startup <2s; 1h soak.
- Tests: `scripts/test.sh` must pass after every task. QML tests use `/usr/lib/qt6/bin/qmltestrunner`; syntax checks use `/usr/lib/qt6/bin/qmllint`. Python tests use `python3 -m unittest`.
- Never edit the user's Hyprland config without a backup and marked begin/end blocks. Installer is idempotent and has `--dry-run`, `--no-start`, and `--purge`.
- Reference sources: Caelestia installed at `/etc/xdg/quickshell/caelestia` and `/usr/lib/python3.14/site-packages/caelestia`; Ricelin at commit `c15f1a4c0db4d7bf5b07070ed097cd0eadf79aed` (`git clone https://github.com/Gakuseei/Ricelin.git /tmp/zestify-ricelin-reference && git -C /tmp/zestify-ricelin-reference checkout c15f1a4c0db4d7bf5b07070ed097cd0eadf79aed`).

## Review Focus

These are the failure modes most likely to hurt a real user; each has a test in the task that owns the code.

1. **Hotplug, rotation, or resolution change:** a 1366x768 portrait panel becomes 768x1366; the pill, surfaces, and proxy target must rescale without clipping or decoding at the wrong size. (Task 3 and Task 13)
2. **Missing or corrupt Caelestia state:** `scheme.json`, a monitor scheme, or a monitor wallpaper file is absent or malformed; the shell must keep running with the global scheme or built-in dark palette. (Task 2 and Task 5)
3. **Proxy generation fails or disk fills:** ffmpeg is missing, the source is unreadable, or the cache write fails; the monitor must show the original or still frame, not black or a hung shell. (Task 5)
4. **Sleep/lock ordering or failure:** audio is playing, hyprlock exits immediately, logind suspends before lock, or DPMS is off; the machine must not suspend unlocked, trap the user, or leave a black screen. (Task 8)
5. **Installer re-run or uninstall after hand edits:** marked blocks are duplicated, backups are lost, or Caelestia is not restored; the installer must be idempotent and reversible. (Task 12)
