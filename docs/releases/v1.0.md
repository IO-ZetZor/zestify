# Zestify v1.0

Zestify's first release provides a standalone Quickshell desktop shell for
Hyprland, with one centered pill per monitor, wallpaper-derived colors, native
animated backgrounds, and a Python CLI. It runs without the Caelestia shell
or CLI.

## Desktop and media

- Compact surfaces for launching apps, media, audio, calendar, network,
  Bluetooth, battery, system monitoring, settings, and power actions.
- A rotating circular album cover in the media surface and hover dashboard.
  Its border now follows each monitor's wallpaper palette, including live
  wallpaper and dark/light changes. Rotation pauses with playback and hidden
  views.
- Lyrics from player metadata or LRCLIB, synchronized highlighting,
  click-to-seek, canceled stale requests, and explicit loading/error states.
- A notification-history drawer opened from the left screen edge, with
  notification actions, replacement handling, Do not disturb, and Clear all.
  Hovering a popup pauses its timeout.
- A redesigned system dashboard with CPU, memory, network, and per-GPU usage
  history. GPU temperature and memory appear when available; suspended GPUs
  remain asleep. AMD, DRM-client counters, and optional NVIDIA telemetry are
  supported.
- On-demand Cloudflare download/upload and latency estimates, with progress,
  cancellation, and retry, available from System and Network.

## Wallpaper and application colors

- A searchable image/video wallpaper gallery with keyboard selection, video
  thumbnails, and current-monitor or all-monitor targeting.
- Per-monitor palettes and live dark/light changes. Primary/global wallpaper
  changes update application colors; secondary-monitor changes stay local.
- Video proxies honor configured resolution, codec, and quality settings,
  with a 30 fps cap. Playback can pause for fullscreen/obscured displays,
  unfocused monitors, low battery, power saver, lock, and DPMS.
- Application theming for Kitty, GTK 3/4, Qt engine, Fuzzel, cava, configured
  Zen profiles, and configured Spicetify installations. Existing app styling
  and unrelated configuration are preserved, with backups for modified files.
- GTK theme slots and native mode notifications refresh supported apps. Zen
  keeps user mods and transparency controls; Spicetify retains the selected
  theme's CSS, JavaScript, and assets.

## Lock, power, and installation

- A top-edge pull-to-lock curtain that follows the pointer. Release past the
  threshold to lock; a short pull or Escape cancels.
- A per-monitor Hyprlock layout with wallpaper/palette, clock/date, battery,
  Caps Lock feedback, keyboard-layout switching, and a Sleep button. The
  active monitor hosts the password form.
- Power action cards with hold confirmation for logout, restart, and shutdown.
  Release or focus loss cancels an incomplete hold; zero idle timeouts disable
  the corresponding session action.
- Idempotent installation, configuration backups, copy-only Caelestia state
  migration, and managed Hyprland keybind/autostart upgrades that preserve
  unrelated user configuration.
- The canonical `zesti` CLI and compatible `zestify` entry point. Shell commands
  use the supported Quickshell instance/IPC interfaces and report command
  failures. Executable paths are quoted correctly in Hyprland bindings.

## Installation and upgrade

From a checkout of this release, run `./install.sh`. Existing installations can
run `zesti update` from a clean checkout, or pull the repository and rerun the
installer. See the [README](../../README.md) for requirements and configuration.

Zen needs a restart after its first integration apply or stylesheet changes.
Existing GTK 3 apps need reopening once when migrating from the old CSS
integration. GTK 4/libadwaita follows mode changes live, but exact custom colors
may need an app restart. Qt theming requires the Qt engine platform-theme
plugin; proprietary NVIDIA telemetry requires `nvidia-smi`.

Online lyrics send track metadata to LRCLIB while a media view is visible.
Speed tests contact Cloudflare only when requested and can transfer about
43 MiB down and 27 MiB up.

## Verification and known limits

Release validation passed: 280 Python tests, 176 QML tests, QML lint, and native
offscreen media/notification checks in dark/light, scaled, and empty layouts.
Both album borders were also checked through live palette and mode changes.
Tests cover installer preservation,
wallpaper/proxy behavior, application theme adapters, telemetry, and UI state
transitions. Hardware-specific GPU readings, actual suspend/shutdown, and a
full one-hour soak are not certified by these automated checks.

The earlier reference-machine measurements exceeded the 250 MB RSS target;
see the dated [acceptance report](../acceptance.md) for measurements and
remaining manual checks.
